  Companion to the Software Requirements Specification, Draft 0.5. It defines the formulas,
  time step, control timings, measurement rules and automated tests. One model drives
  both the Build screen preview and the run (FR-3). A reference implementation of this
  specification reproduces all 135 values in the Simulation sheet of the Component Values
  sheet exactly, to the sheet's 3 decimal places.


  Constants and units
  All quantities are SI: metres, seconds, kilograms, newtons. Calculations use double-
  precision numbers and no random values (FR-29).

  Build quantities
  Each build is one chassis, one set of wheels and one motor (FR-1). The surface supplies
  μ_r (rolling friction) and μ_g (grip); the wheels supply the factors k_r and k_g (FR-9).

     mass                             m       = m_chassis + m_wheels + m_motor
     weight                           R       = m × g
     rolling friction                 F_r     = μ_r × k_r × R
     grip limit                       F_lim   = μ_g × k_g × R
     max acceleration                 a_max   = (min(F_d,max , F_lim) − F_r) ÷ m
     max braking                      b_max   = (min(F_b,max , F_lim) + F_r) ÷ m
     top speed                        v_max   = the motor's top speed


  The Build screen shows these values for each surface in the mission (FR-2) and computes
  them with this same code (FR-3).


  Controls
  Throttle level u_t and brake level u_b run from 0 to 1 (FR-6).

       Held: the level rises by Δt ÷ T each step, up to 1. Throttle takes 1.0 s from 0 to 1, brake
       0.5 s.
       Released: the level falls at the same rate, down to 0. The sheet's simulations hold the
       controls throughout, so no mission value depends on the release rate. It is a starting
       value for playtesting.
       Both held: the brake applies and the throttle counts as released (FR-6).
       Level used in a step: the level at the end of that step. From rest, the throttle level in
       step n is min(1, (n + 1) × Δt ÷ T_t).
       Locks: in Mission 2 the throttle drops to 0 at the power-cut line and stays locked (FR-
       39). In Mission 3 the throttle is locked for the whole attempt (FR-30).
       Steering changes the direction of travel, never the speed, and a stopped rover does
       not turn (FR-27). Distances are measured along the path driven. Turn rate: TBD, set in
       playtesting; it does not change any speed, distance or time in this specification.


  Driving states and acceleration
  In each step the rover is in exactly one state (SRS 3.4). Driving force is F_d = min(u_t ×
  F_d,max, F_lim) and braking force is F_b = min(u_b × F_b,max, F_lim). The wheels slip, and
  the screen shows it, whenever u_t × F_d,max or u_b × F_b,max exceeds F_lim (FR-9).

  The fixed time step, in order
  The simulation advances in steps of Δt = 1/120 s, independent of the frame rate (FR-29).
  Within a step every force is constant, so speed and distance follow the equations of
  motion exactly (FR-10). Each step does the following, in this order:

   1. Read the controls and update u_t and u_b (Controls).
   2. Work out F_d, F_b and F_r from the current mass and surface.
   3. Choose the state and its acceleration a (Driving states). If v = v_max and a > 0, set a =
      0.
   4. Move for one step with that constant a:
             Speed: v' = v + aΔt. Distance: d = vΔt + ½aΔt².
             If v' would pass v_max, the rover reaches v_max at t₁ = (v_max − v) ÷ a and holds it
             for the rest of the step: d = vt₁ + ½at₁² + v_max(Δt − t₁).
             If v' would fall below 0, the rover stops at t₁ = −v ÷ a and stays stopped: d = vt₁ +
             ½at₁².
   5. Add d to the distance along the path and advance the clock by Δt.
   6. Check the mission's lines and limits (Mission measurement).

  Power-ups
  A power-up multiplies one variable from the step after its question closes, for the rest of
  the attempt (FR-38). Only one is active; taking another replaces it (FR-40).

  Motor boost raises F_d,max, but the driving force can never exceed F_lim. On sand it is
  capped by grip in 16 of the 27 builds, so part of the extra force is lost to wheel slip.

  Checked against all 27 builds with this model:

       Mission 1: Taken at the start of the route, a power-up lets 5 of the 7 failing builds pass.
       Mission 2: Grip tyres let all 18 failing builds pass, and Smooth bearings let the 9 spiked-
       wheel builds pass.
       Mission 3: Brake boost lets all 4 failing builds pass. Grip tyres let none of them pass,
       because all 4 are limited by brake force, not grip.
