# Extracted copies

Plain-text copies of the source documents in `docs/specs/`, for searching and quick reading.

- `*.txt`: text of each PDF (`pdftotext -layout`). Diagrams are not included; open the PDF for those.
- `component_values_*.csv`: one file per sheet of `Rovem_Component_Values.xlsx`, as calculated values.

The originals govern. When a source document is replaced, regenerate these files from it.
