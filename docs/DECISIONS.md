| 2026-10-13 | OI-10: The slip flag counts only the force the current state actually uses. Drive slip (u_t·F_d,max > F_lim) only in Driving or At top speed; brake slip (u_b·F_b,max > F_lim) only in Braking. Stopped, Coasting and Cruising never show slip. This narrows the Physics Spec's literal "whenever u_t × F_d,max or u_b × F_b,max exceeds F_lim" (PENDING E9). Reason: the Physics Spec defines F_b only for a moving rover (b = (F_b + F_r)/m); a parked rover with the brake held needs no friction from the ground, so its tyres cannot slide.
