| 2026-10-13 | OI-10: The slip flag counts only the force the current state actually uses. Drive slip (u_t·F_d,max > F_lim) only in Driving or At top speed; brake slip (u_b·F_b,max > F_lim) only in Braking. Stopped, Coasting and Cruising never show slip. This narrows the Physics Spec's literal "whenever u_t × F_d,max or u_b × F_b,max exceeds F_lim" (PENDING E9). Reason: the Physics Spec defines F_b only for a moving rover (b = (F_b + F_r)/m); a parked rover with the brake held needs no friction from the ground, so its tyres cannot slide. The old code showed "Wheels slipping: on" for a rover parked on sand with S held (1500 N requested > 1024 N grip). Leftover throttle during Braking is ignored (OI-1), so it cannot cause slip either. | Chosen by Claude at k._muz's request (2026-10-13) | M4, M10, M11 |
| 2026-10-13 | OI-9: In the balance report and the Pass check sheet, a Mission 3 "pass" means the build *can* pass: its stopping distance from the brake line is at most 23 m (the zone end). Proof: braking s ≥ 0 m after the line stops the front at s + d; the pass rule needs 19 ≤ s + d ≤ 23 (zone start + 2 m to zone end); s = max(0, 19 − d) satisfies it exactly when d ≤ 23. A real attempt is judged by the Physics Spec rule (`classifyStop`). The Physics Spec text is correct as written; only the sheet column needs a note (PENDING E8). | k._muz | M2, M11 |
| 2026-10-13 | Relative imports name the file extension (`.ts`, `.tsx`); JSON is imported `with { type: 'json' }`; only erasable TypeScript syntax (no `enum`, `namespace` or parameter properties). Reason: `npm run balance` runs `scripts/balance.ts` in Node 24 with type stripping, which neither resolves extensionless imports nor compiles non-erasable syntax. `erasableSyntaxOnly` enforces the syntax half in `typecheck`; CI runs `npm run balance` to enforce the import half. Applied to all of `src/` so there is one rule, not a per-folder one. | k._muz | All |

State label: At top speed when v = v_max and F_d ≥ F_r; otherwise Driving, which includes negative a when F_d < F_r (e.g. throttle falling at top speed), so the rover slows. If v reaches 0 inside a step, the existing step split applies and the rover is Stopped. | k._muz | M2 |
